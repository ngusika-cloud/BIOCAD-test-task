# Тестовое задание

Full-stack разработчик AI-native продукта (React + FastAPI)

## Задача

Пользователь открывает веб-страницу и сразу видит интерактивную диаграмму Гантта с загруженными тестовыми данными (засидированными). Также можно загрузить свой Excel со списком задач.

Рядом с диаграммой — чат, через который можно на естественном языке массово редактировать план: переносить задачи, менять зависимости, добавлять новые, перераспределять исполнителей. Изменения от агента мгновенно отражаются на диаграмме.

По клику на задачу открывается модалка с деталями — что именно показывать внутри, решаете сами.

План можно экспортировать обратно в Excel.

## Обязательный стек

- Фронт: React
- Бэк: Python / FastAPI
- MCP
- LLM через API

## Формат входного Excel

Колонки: задача, описание, исполнитель, длительность, предшественники.

## Что вы отправляете

- Ссылку на git-репозиторий
- Ссылку на развёрнутое приложение (Render, Vercel, Fly.io, собственная VM — на ваш выбор)

В репозитории должно быть:

- README с инструкцией запуска, описанием архитектуры и принятых решений, а также отдельным разделом о том, как вы использовали AI-ассистентов при разработке
- Демо-видео или gif основного сценария: загрузка Excel → правка через чат → экспорт
- Пример Excel для теста
- Документ «Roadmap to production» — что нужно доработать, чтобы довести решение до боевого состояния: технические долги, оставленные сознательно, чего не хватает для продакшена, риски, порядок закрытия
